| 항목 | 내용 |
|------|------|
| **프로젝트명** | Mini HIS (Hospital Information System) |
| **진행 기간** | 2025.11.03 ~ 2025.11.11 |
| **참여 인원** | 1명 |
| **담당 역할** | PM, 백엔드 및 클라이언트 전체 개발 |

---

## 🧩 프로젝트 개요

의료기관의 진료 과정에서 발생하는 환자 정보, 진료 기록, 검사 오더 및 결과, 보험 청구 데이터를 통합 관리하는 **병원정보시스템(HIS)** 을 학습용으로 구현했습니다.  
Oracle 기반 데이터베이스와 WinForms UI를 통해 실제 병원 전산 환경과 유사한 구조를 구성했습니다.

## 🧰 개발 중 발생한 이슈 & 해결 과정

| 구분 | 문제 상황 | 원인 분석 | 해결 방법 |
|------|-------------|-------------|-------------|
| **이벤트 실행 안 됨** | 버튼 클릭, 폼 로드 시 반응 없음 | 이벤트 핸들러 미연결 | 폼 디자인 → ⚡ 이벤트 탭 → `Load` 또는 `Click` 연결 |
| **탭 이동 순서 이상** | Tab 키 이동 순서 비정상 | `TabIndex` 자동 배정 오류 | 각 컨트롤의 `TabIndex` 수동 조정 |
| **DB 변경 미반영** | INSERT/UPDATE 후 반영 안 됨 | Oracle AutoCommit 기본 OFF | `COMMIT;` 명령 또는 코드 내 커밋 추가 |
| **Grid 하단 빈 행** | DataGridView 마지막 빈 행 표시 | `AllowUserToAddRows = true` | `AllowUserToAddRows = false` 설정 |
| **날짜에 시간 포함** | DATE 필드에 시간 표시 | Oracle DATE 타입 기본 시간 포함 | `TO_CHAR(BIRTH, 'YYYY-MM-DD')` 적용 |
| **데이터 삭제 처리** | DELETE 시 데이터 완전 삭제 | 의료데이터 보존 필요 | `IS_DELETED` 또는 `STATUS` 변경으로 논리삭제 |
| **PK 자동 증가 실패** | “ORA-02289: 시퀀스가 존재하지 않습니다.” | Oracle은 AUTO_INCREMENT 미지원 | 시퀀스 생성 후 `NEXTVAL` 사용 |
| **Form1.cs 복잡도** | 코드 집중으로 유지보수 어려움 | 기능별 Form 미분리 | `TreatmentForm`, `BillingForm` 등으로 모듈화 |

## 🧯 Oracle 트러블슈팅 요약

| 오류 코드 | 증상 / 메시지 | 원인 | 해결 방법 |
|------------|----------------|--------|-------------|
| **ORA-65096** | 공통 사용자 이름이 부적합 | CDB 환경에서 사용자 생성 시도 | PDB(XEPDB1)로 이동 후 생성 (`ALTER SESSION SET CONTAINER=XEPDB1;`) |
| **ORA-01017** | 사용자명/비밀번호 불일치 | 잘못된 계정정보 또는 서비스명 | 계정/비밀번호 및 `SERVICE_NAME=XEPDB1` 확인 |
| **ORA-02289** | 시퀀스 존재하지 않음 | 참조 시퀀스 미생성 | `CREATE SEQUENCE` 명령 실행 |
| **ORA-07145** | 바인드 변수명 부적합 | 파라미터명 불일치 | SQL에는 `:param`, 코드에는 `"param"` 형태로 지정 |

## 💡 추가 팁

- Oracle은 기본적으로 **AutoCommit = OFF** 입니다.  
  COMMIT 명령을 실행해야 실제 반영됩니다.
- `DataGridView.AllowUserToAddRows` 옵션은 **false** 로 설정해야 등록 버튼 기반 입력 시 깔끔하게 표시됩니다.
- **날짜 포맷**은 `TO_CHAR()` 로 변환해 시간 제거.
- **삭제는 논리삭제** 방식(STATUS 변경 또는 플래그 컬럼).
- **모듈화(Form 분리)** 를 통해 코드 유지보수성을 확보하세요.

## 🪞 프로젝트 회고 (Retrospective)

| 항목 | 내용 |
|------|------|
| **배경** | HIS는 병원의 진료, 검사, 청구 데이터를 관리하는 핵심 시스템으로, 실제 현업에서는 **Oracle DB + C# 클라이언트(WinForms/WPF)** 조합이 일반적입니다. |
| **배움의 과정** | 대학 시절 데이터베이스 수업에서 Oracle을 처음 접했지만, 이후 주로 MySQL/MariaDB 환경에서 개발했습니다. 이번 프로젝트를 통해 병원 전산에 사용되는 Oracle 구조를 실습하며 다시 익힐 수 있었습니다. |
| **기술적 성장** | Oracle 시퀀스, 트랜잭션, 논리삭제, `TO_CHAR()` 활용 등 실무 중심의 DB 제어 개념을 학습했습니다. |
| **C# 경험 확장** | WinForms UI 배치, 이벤트 연결, DataGridView 구성 등 클라이언트 프로그래밍 역량을 강화했습니다. |
| **도메인 이해** | 환자→진료→검사→청구로 이어지는 병원 프로세스 흐름을 직접 설계하며 의료IT의 핵심 구조를 이해했습니다. |
| **느낀 점** | 이번 프로젝트를 통해 Oracle과 C#을 활용한 병원정보시스템의 기초를 체계적으로 익힐 수 있었고, 의료IT 엔지니어로서 한 단계 성장한 의미 있는 경험이었습니다. |
